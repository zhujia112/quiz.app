# quiz.app
# 软考做题小程序（网页版 H5）

一个直接跑在浏览器里的刷题工具。题库来自 PDF《计算题专题、真题答案及解析.pdf》，按「第 X 章」自动提取为结构化数据，支持章节练习、错题库、收藏、重做、进度记忆等。

> 纯前端，无需后端、无需联网、无需安装。手机和电脑浏览器都能用。

---

## 一、功能总览

| 功能 | 说明 |
|---|---|
| **章节练习** | 首页按章展示，可进任意章做「顺序练习 / 随机练习 / 错题重练 / 收藏练习」。 |
| **全部练习** | 首页一键「全部顺序 / 全部随机」跨章刷题。 |
| **三种题型支持** | 单选题（选选项即时判对错）、计算/简答题、案例分析题（点「显示答案」后自评对错）。 |
| **答对自动跳、答错停留** | 单选题答对约 0.55 秒后自动跳下一题；答错则停留展示正确答案与解析。计算/案例题自评「答对」则跳，「答错」则停留并收入错题库。 |
| **每章进度记忆** | 单章顺序练习时记录最后做到的第几题；再进该章显示「继续上次（第 N 题）」，直接跳转。完成本章后进度自动清除。 |
| **清空重做** | 章节页「清空本章记录并重新做题」：清空本章进度 + 已做 + 错题（收藏保留），从头再刷。 |
| **错题库** | 答错自动入册，可单独列表查看、整组重练、点错题直达该题。 |
| **收藏夹** | 做题时一键 ★ 收藏，可单独列表、整组练习。 |
| **做完判分与汇总** | 完成一组练习时显示「答对 / 总题数」及答对、答错、未判定统计，可「再来一次」或返回首页。 |
| **进度统计** | 首页顶部展示总题数、已练习、错题库、收藏数量；章节卡片显示错题数、已做/未做、「▶ 有进度」标记。 |
| **数据本地持久化** | 记录存浏览器 `localStorage`，刷新/关掉重开不丢（见「数据与存储」）。 |

## 二、页面结构

应用为单页（SPA），内部切换 5 个「屏」（screen），底部在练习页显示上一题/下一题导航。

```
┌─────────────────────────────────────────┐
│ 首页 (home)                               │
│  · 顶部统计：总题数 / 已练习 / 错题库 / 收藏 │
│  · 按钮：全部顺序、全部随机、📕错题库、⭐收藏 │
│  · 章节网格（每章卡片：章名/题数/错题·已做标记）│
└───────────────┬─────────────────────────┘
                │ 点章节卡片
                ▼
┌─────────────────────────────────────────┐
│ 章节详情 (chapter)                         │
│  · 章名、题数、错题/收藏数                  │
│  · 按钮：继续上次 / 顺序练习 / 随机练习      │
│         错题重练 / 收藏练习 / 清空本章记录    │
└───────────────┬─────────────────────────┘
                │ 选一种方式
                ▼
┌─────────────────────────────────────────┐
│ 做题 (practice)          ← 底部显示导航     │
│  · 顶栏：退出 / 标题 / 第N题·共M题          │
│  · 进度条                                  │
│  · 题目卡：题型标签·章节·★收藏 / 题干 /      │
│         [单选]选项(判对错高亮) /             │
│         [计算/案例]显示答案→参考答案+自评    │
│  · 底部导航：←上一题  下一题→(末题显示完成) │
└───────────────┬─────────────────────────┘
                │ 做完最后题
                ▼
┌─────────────────────────────────────────┐
│ 完成汇总 (practice 内)                     │
│  · 答对/总题数 · 答对·答错·未判定            │

└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ 列表 (list)  —— 错题库 / 收藏夹             │
│  · 标题 + 开始练习(数量) 按钮                │
│  · 题目列表（点任一条直达该题）              │
└─────────────────────────────────────────┘
```

## 三、项目文件结构

```
quiz/
├── index.html          # 主页面（引用外部 bank.js / app.js / styles.css）
├── standalone.html     # 自包含版（样式+题库+逻辑全部内联，双击即开，零依赖）
├── app.js              # 全部交互逻辑（做题、判分、错题、收藏、进度记忆）
├── styles.css          # 暗色主题样式
├── bank.js             # 题库数据（window.BANK），由 extract.py 生成
├── bank.json           # 同一份题库的 JSON 格式，便于人工校正
├── extract.py          # PDF 题库解析器（切章→按题型解析→输出 bank.js / bank.json）
└── build_standalone.py # 一键把 index.html + 资源拼成 standalone.html
```

> **index.html vs standalone.html**
> - `standalone.html`：单文件、内联题库，双击 `file://` 直接打开，适合随手刷题。
> - `index.html`：引用外部文件，更标准、便于改题库后只替换 `bank.js`；推荐用本地服务器打开（`python -m http.server`，归属 `http://localhost` 源，存储最稳）。

## 四、数据与存储

题库（`window.BANK`）结构：

```js
{
  chapters: [
    { num: 4, name: "章节名", count: 题数,
      questions: [
        { id: "4-1", type: "single", stem: "题干",
          options: [{key:"A",text:"..."}, ...], answer: "B",
          analysis: "解析（可能为空）" },
        { id: "6-3", type: "calc", stem: "题干",
          answer: "参考答案", analysis: "解析" },
        { id: "25-1", type: "case", stem: "背景+问题",
          answer: "参考答案", analysis: "" }
      ] }
  ]
}
```

题型：`single`（单选）/ `calc`（计算·简答）/ `case`（案例分析）。

本地存储（`localStorage`，键名带 `_v1` 版本后缀）：

| 键 | 内容 |
|---|---|
| `quiz_done_v1` | 已做题结果 `{qid: "ok"|"wrong"}` |
| `quiz_wrong_v1` | 错题库 `{qid: 时间戳}` |
| `quiz_fav_v1` | 收藏 `{qid: 1}` |
| `quiz_progress_v1` | 每章进度 `{chapterNum: qid}` |

说明：刷新/重开不丢；清浏览器数据、换浏览器/设备会丢；预览面板（`file://`）与本地双击可能不在同一存储域，记录不互通。

## 五、使用方式

1. **最省事**：双击 `standalone.html`（Chrome/Edge 直接打开即可刷题）。
2. **最标准**：在 `quiz/` 目录下执行 `python -m http.server 8123`，浏览器访问 `http://localhost:8123/index.html`。
3. 上方预览面板直接打开 `standalone.html` 也可即时使用。

## 六、校正题库（可选）

题库由 PDF 自动解析，因 PDF 排版异构，约 2.5% 单选题答案字母未被命中、个别题干偏短（公式/表格保留为原文文本）。需要微调时：

1. 编辑 `quiz/bank.json`，按题号 `id`（如 `"4-1"`）定位修改 `stem / options / answer / analysis`。
2. 重新生成数据与应用：
   ```bash
   # 若仅改 bank.json 后再生成 bank.js：用 extract.py 或手动导出
   python extract.py                 # 重新从 PDF 解析（覆盖 bank.js / bank.json）
   python build_standalone.py        # 重新打包 standalone.html
   ```
3. 刷新页面生效。

> 注：`extract.py` 从原始 PDF 重新解析会覆盖 `bank.json`。若只改数据不想重解析，可直接改 `bank.json` 后，用 `build_standalone.py` 拼装（需先把 `bank.json` 写回 `bank.js` 格式，或调整脚本读取来源）。

## 七、题库来源与规模

- 来源：PDF《计算题专题、真题答案及解析.pdf》（软考「系统集成项目管理工程师」方向），855 页，加密但实际无需密码、文本可提取。
- 规模：**22 章 / 约 1995 题**（单选约 1820、案例分析约 120、计算·简答约 55）。
- 主体是计算题 + 第 25 章案例分析真题，纯「单选题」较少（多为填空式），三类题型均已支持。
